# v0.2.1 SOCKS 导入修复验证摘要

验证日期：2026-11-07。本补丁修复 SOCKS 链接中整段 Base64 认证信息被当作用户名、密码留空的问题。以下为历史检查的公开摘要，整理时未重跑测试。

## 修复范围

当 SOCKS 链接没有显式用户名、密码分隔符时，尝试解码 Base64 userinfo，并按第一个冒号拆分用户名和密码；密码中的后续冒号完整保留。支持 `socks`、`socks5`、`socks5h` 别名，以及标准、URL-safe、有补位和无补位 Base64。

显式 `用户名:密码`（含显式空密码）保持原值，没有认证的链接继续不带认证。HTTP 认证不使用 SOCKS 分享链接编码规则。相同行为适用于订阅导入。

## 历史验证结果

- 31 项专项回归通过，覆盖编码形式、协议别名、链接与整段 Base64 订阅、认证特殊字符、无认证、明文认证及 HTTP 行为。
- `go test ./...`、`go vet ./...` 通过，实际 Xray 核心配置检查通过。
- Windows amd64、Linux amd64、Linux arm64 构建通过。前端未变，复用既有构建资源。
- 隔离回环实例的 API 导入与存储结果检查通过，覆盖编码认证、明文认证与整段 Base64 订阅，确认导入字段不丢失。
- Linux amd64 的 `0.2.0` → `0.2.1` Web 面板升级检查通过，既有账户、资源归属、上游配置、订阅与核心版本兼容性检查通过。
- 既有 x-ui、Xray 与独立中转核心的进程启动状态、程序及配置完整性、监听状态在面板更新前后保持一致。

## 未覆盖环境

隔离导入验收没有连接第三方 SOCKS 服务，不能据此判断上游网络可达性。ARM64 仅做交叉构建，未进行实机运行。前端资源未重新构建；本记录也未覆盖当前发布安装器、完整卸载或升级失败恢复的实机测试。
