# v0.2.4 变更与本地验证记录

本版统一使用“入口节点、出口节点、转发管理”，同步导航、概览、表单和提示，并增大正文、导航、表格、表单及辅助文字字号。

出口节点列表增加检测操作和结果展示，复用现有隔离 Xray 探测接口。检测来源限于同一用户的入口节点，无需预先创建转发或应用配置。新增可选的任务上游 ID、结果任务 ID，使排队、运行、失败和成功结果能够在页面刷新后准确关联；旧记录保持可读取。

引擎修正 IPv4 失败、IPv6 成功时将部分可用错误判为整体失败的问题。IPv4-only 行为保持原有成功语义，并单独展示 IPv6 错误。

## 已通过的本地检查

- 完整后端 `go test ./...` 和 `go vet ./...`。
- 14 项前端状态回归：同 owner 与本机节点权限、刷新后的排队状态、排队重试失败覆盖旧成功、旧失败不覆盖新成功、任务与结果关联、仅 IPv6 部分可用、空地址不判可用、中断状态、旧记录和旧登记任务兼容，以及检测来源选择。
- 后端新增检测关联持久化、失败、中断与旧记录兼容回归，以及双栈结果聚合场景。
- TypeScript/Vite 前端构建及 Windows 面板、节点管理程序构建。

## 浏览器检查与限制

浏览器环境使用隔离测试账户、合成入口/出口配置、真实 API/认证/存储以及受控探测运行时。准备阶段未提交检测，也未连接真实代理或生产节点。

浏览器 DOM 读取确认了新导航、概览文案和版本，并测得正文 15px、导航 16px。截图通道返回 `browser screenshot surface preparation timed out after 3000ms`；原生导航点击也超时。后续只做了只读定位诊断，没有通过脚本点击、修改页面状态或改变 URL 绕过失败。

因此本次浏览器的截图、点击流程和响应式视觉验收均未完成，不能将源码、DOM 或自动测试代替视觉通过结论。未取得可交付截图，当前浏览器接口也未提供可用的控制台日志读取能力。

发行流程另行执行 Linux 测试、双架构构建、归档检查与一次性 systemd 生命周期验收；本记录不预先宣称这些发布任务的结果。
