# v0.2.0 历史验证摘要

验证日期：2026-11-07。本版本增加官方 Xray-core 版本列表、自定义 tag、多用户、资源归属和公开注册开关。以下为既有验证结果的公开摘要，整理时未重跑测试。

## 构建与核心版本兼容性

| 检查 | 历史结果 |
| --- | --- |
| `go test ./...` | 通过，包含账户、权限、存储迁移、版本目录及执行器测试 |
| `go vet ./...` | 通过 |
| TypeScript + Vite 正式构建 | 通过 |
| Windows amd64 构建 | 通过，并完成 HTTP 与浏览器功能检查 |

历史核心兼容层仅转换等价别名，如 RAW/TCP 与 REALITY target/dest。协议及传输是否可用仍以所选核心的实际校验为准。

## 多用户与迁移检查

HTTP 验收在隔离回环实例中进行。下列检查通过：

- 注册默认关闭；管理员可控制开关，关闭后不影响已有账户登录或管理员创建账户。
- 注册仅要求用户名和密码，新账户固定为普通用户；重复用户名检查忽略大小写。
- 普通用户无法访问用户管理、修改全局设置或管理面板本机节点。
- 节点、上游、转发、订阅来源、任务及探测结果按账户过滤，管理员可全局查看。
- 13 项跨用户访问控制检查通过，覆盖详情、分享、修改、删除、日志、应用、检测及服务操作。
- 跨用户关联和越权变更归属被拒绝；管理员编辑保留原资源归属。
- 个人订阅仅包含本人启用入口，管理员个人订阅遵循相同规则；令牌轮换范围按账户隔离。
- 普通用户可取得官方核心目录，自定义 tag 的规范化检查通过。

存储与 API 自动测试还覆盖 v1 数据库迁移、认证兼容性、个人订阅兼容性、已应用状态、逐请求实际角色检查及禁用入口过滤。

## 浏览器检查

登录、资源归属显示、用户管理、官方版本选择、自定义预发布 tag、注册开关和普通用户权限展示通过功能检查。版本选择的未保存提示、恢复原值后的提示清除，以及未保存操作不触发应用的检查通过。

窄屏尺寸检查没有整页横向溢出。普通点击工具间歇性超时，部分交互以已定位控件的 DOM 点击完成；截图视觉验收未完成。

## 升级与隔离结论

历史 Linux amd64 的 `0.1.0` → `0.2.0` Web 面板升级及健康检查通过，既有账户、资源归属、上游配置、个人订阅与已应用状态兼容性检查通过，注册保持默认关闭。

既有 x-ui、Xray 与面板专用节点的进程启动状态、程序及配置完整性、监听状态在 Web 面板升级前后保持一致。独立 Windows Xray 客户端经原有 VLESS-REALITY 公网入口及上游的 IPv4 链路检查通过。该次升级未触发回滚，不构成升级失败恢复的实机证明。

## 未覆盖环境

未覆盖 ARM64 实机运行、每个历史核心版本、每种协议组合的公网转发、完整截图视觉验收或持续性能基准。历史升级结果不能替代 `v0.2.2` 发布安装器及完整卸载的专门验证。
